# CODSOFT Internship - Python Projects

This repository contains the tasks completed for the CodSoft Python Programming Internship.

## Tasks

### Task 1: Chatbot
A simple rule-based chatbot built in Python. It uses regular expressions (pattern matching) to detect keywords in user input and responds with pre-written replies. This project demonstrates the basics of conversation flow and simple natural language processing.

**File:** `Chatbot-task1.py`

**How to run:**
```
python Chatbot-task1.py
```

### Task 2: Tic-Tac-Toe AI
An unbeatable Tic-Tac-Toe game where the AI uses the Minimax algorithm (with Alpha-Beta Pruning) to always play optimally. This project demonstrates basic game theory and search algorithms.

**File:** `Tic_tac_toe_AI_TASK2.py`

**How to run:**
```
python Tic_tac_toe_AI_TASK2.py
```

## Tools Used
- Python 3
- Built-in libraries: `re`, `random`, `math`

## About
These projects were built as part of the CodSoft internship to practice core Python concepts including functions, classes, loops, pattern matching, and recursion.
