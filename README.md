Hey! This repo has the projects I built for the CodSoft Artificial Intelligence internship.
What’s in here

Task 1 — Chatbot
A simple chatbot that replies based on keywords it recognizes in what you type. It’s not “real” AI — it just uses regex (pattern matching) to spot phrases like “hi” or “how are you” and picks a matching response. 
Objective : Intro to how conversation flow and basic NLP work.
Run it with: python Chatbot_Task1.py


Task 2 — Tic-Tac-Toe AI
A Tic-Tac-Toe game where you play against an AI that never loses. It uses the Minimax algorithm (plus Alpha-Beta Pruning to make it faster) to think through every possible move before deciding what to play. 
Objective : To understand game theory and how search algorithms work.
Run it with : python Tic_tac_toe_AI_TASK2.py
